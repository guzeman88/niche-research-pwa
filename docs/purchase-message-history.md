# Preserving an already-permitted purchase-message capture

The automatic evidence bridge now retains an already-returned, validated public
purchase message with its original wording, numeric value, unit, bound, window
and actual page-capture time. It excludes private fields. A fetched page with no
recognized line retains only an unavailable status and its capture time; that
status suppresses overlapping older messages without inventing wording or a zero.
A cached review window cannot backdate a newly fetched page. Conflicting messages
remain unknown. The private calculation exposes the preserved purchase evidence.

This adds no request, approval scope, scheduler, conversion assumption or model
activation. Current protected access excludes automated listing pages; this fix
does not enable that source. The ordinary parser identifies explicit people as
buyers and otherwise leaves the unit unknown. Neither becomes verified purchases,
and lower bounds remain bounds. The existing untrained estimate stays unknown
without the required conversion evidence.

## Remaining prospective comparison gap

[eMarketInsight's methodology page](https://www.emarketinsight.com/pages/how-our-data-works),
reviewed November 5, 2026, describes daily listing tracking and a purchase-message
signal, with stock changes used when that signal is absent. Its caveats include
restocks, made-to-order products and large inventories. This does not disclose its
full implementation or establish order accuracy.

EtGen retains public API quantity snapshots, but its current automatic untrained
lane does not sum decreases across the teacher's complete reporting interval.
The trained feature only considers the last two stock readings. A comparable
prospective test needs a frozen listing panel retained for the entire declared
window, dated snapshots with gap/restock/conflict coverage, and a separately
labelled inventory-change heuristic. Stock decreases must not be presented as
observed purchases. Missing historical windows cannot be reconstructed from a
single current count. Freeze the heuristic and predictions before obtaining the
matching teacher report; unknown exact provider endpoints remain a comparison
limit. Existing reference labels and precision results stay unchanged.
